# Frame Control 0.4.63

- Framey notification actions run once and retire after dismissal or expiry. [#696](https://github.com/saphid/frame-control/pull/696)
- Framey ignores oversized ownership receipts while retaining conservative installed-state reporting. Receipts up to 16 KiB remain supported. [#695](https://github.com/saphid/frame-control/pull/695)
- Plugin pages refresh when a route is replaced, and old-page cleanup preserves its replacement. [#697](https://github.com/saphid/frame-control/pull/697)
- Plugin authors can register memoized and ref-forwarding React components as local Framey pages, retaining existing element props and refs. [#704](https://github.com/saphid/frame-control/pull/704)
- Plugin authors can show checkbox descriptions and tooltip text without hover, including disabled controls. [#703](https://github.com/saphid/frame-control/pull/703)
- Slow event polls retain queued plugin output; closing a panel removes its subscription immediately. [#701](https://github.com/saphid/frame-control/pull/701)
- AlarMe preserves paused timers across Decky restarts after managed Update/reinstall of its pinned 1.6.3 archive. [#496](https://github.com/saphid/frame-control/pull/496)
- Plugin authors receive a structured error for ZIP files with damaged DEFLATE data. [#700](https://github.com/saphid/frame-control/pull/700)
- The example settings plugin gains native AMD64 and ARM64 Decky restart checks for saved settings, refused damaged/future data and clean shutdown. [#698](https://github.com/saphid/frame-control/pull/698)
- Notebook regression checks verify per-app pages, selections and strokes across a real Decky restart, including deletion that preserves other notes. [#497](https://github.com/saphid/frame-control/pull/497)
- Runtime tests reject unclean Syncthing shutdown and exercise a separate private Terminal candidate. Shotty documentation records its isolated native screenshot-copy checks. These checks do not enable managed Syncthing or official Terminal installation. [#513](https://github.com/saphid/frame-control/pull/513), [#490](https://github.com/saphid/frame-control/pull/490), [#498](https://github.com/saphid/frame-control/pull/498)
- Managed Bluetooth and Non-Steam Badges copies shut down cleanly after an IPC disconnect. Badges reads the current user's shortcuts after Update/reinstall. [#702](https://github.com/saphid/frame-control/pull/702), [#503](https://github.com/saphid/frame-control/pull/503)
- PlayTime regression checks verify separate users' saved sessions, paused tracking and statistics across a real Decky restart. Automatic game-time recording remains unverified. [#511](https://github.com/saphid/frame-control/pull/511)
- The support matrix now links the v0.4.62 installer and update-channel audit. [#634](https://github.com/saphid/frame-control/pull/634)

CI, tagged installer builds, independent downloaded-artifact audit and locked
real Frame smoke. No v0.4.63 tag exists yet.
