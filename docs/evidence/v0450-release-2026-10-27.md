# v0.4.50 tagged release verification, 27 October 2026

The annotated `v0.4.50` tag dereferences to merged main commit
`2797212d8c95311deb8ba73043d0f90ba10bc962`. Its tree exactly matched
the reviewed [candidate PR #360](https://github.com/saphid/frame-control/pull/360)
head `dab13fa8763b4f836cd49d398d152124655ea8dc`. The candidate includes
the Framey and Windows changes listed in the public release notes and the
publisher gate that checks every workflow run attempt.

  e2e, iOS, Windows, macOS, Linux and the aggregate gate.

  preview and skipped by their tag-only conditions; they were not release gates.
- The [exact-tag release workflow](https://github.com/saphid/frame-control/actions/runs/40442228066)
  then passed all six jobs on its first attempt: draft, four platform builds,
  and checksums. No tagged job failed, was cancelled, skipped or overridden.
