## Remaining release gates

The candidate needs green exact-head PR CI, e2e, native Decky runtime and all
four installer previews. After the candidate merges, its exact main commit
needs green CI and e2e. The tagged release then needs every installer build,
ten assets, matching checksums, release verification, independent package
checks and publisher dry run. A failed, cancelled, skipped, pending or
unverified release gate holds publication. The current published release
remains v0.4.50.
