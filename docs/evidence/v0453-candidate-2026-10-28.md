## Gates still required

This smoke is evidence for the versioned source candidate, not a release.
The final candidate must include the green support-matrix [PR #379](https://github.com/saphid/frame-control/pull/379)
and pass its own exact-head CI, e2e, native Decky runtime and four installer
previews. Its final merged main commit must then pass exact-commit CI, e2e
and native runtime. The tag must build all four installer jobs and checksums
without failed, cancelled, skipped or overridden gates. Independent package
checks, release verification and a successful publisher dry run are required
before publication. Any unfinished or failed gate holds v0.4.53 as a draft.
