## Installer and publication checks

Before publication, `scripts/audit-release-assets.py` independently
downloaded all ten installers by asset ID, checked their size and SHA-256
against GitHub metadata, matched `SHA256SUMS` byte for byte, inspected package
formats and versions, and launched the x86-64 AppImage under isolated Xvfb.
The publisher dry run passed exact-commit, smoke, asset and checksum gates.

The publisher repeated those gates, uploaded and read back `update.json`, then
published [v0.4.56](https://github.com/saphid/frame-control/releases/tag/v0.4.56)
at **23:17:16 UTC**. GitHub's latest-release API returned this tag with
`draft=false`, `prerelease=false`, ten installers, `SHA256SUMS` and
`update.json`.

The [postpublication asset audit](v0456-assets-2026-10-29.json) downloaded
all ten public installers again and passed the same hash, checksum, format,
version and isolated AppImage launch checks. It verified the public update

`4f9bf3e1bfb73181af63a5fb73291ee60e8b51bcd3fa88fe09a730cf415273b8`;
