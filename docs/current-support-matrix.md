# What we have tested

Current published release: Frame Control **v0.4.62**, 14 November 2026. **Hardware smoke for v0.4.62 is unverified:** Frame SSH timed out; no worn-headset check ran. Rows identify the last direct check of each feature; an older row does not mean the latest installer was retested on that hardware. “Real Frame + physical PC” means an actual headset and a non-virtual computer. “VM only” means a Windows virtual machine, sometimes connected to the real Frame. A CI test or a simulated device is **not** a physical hardware test. See each link for the exact procedure and limits.
