Import Android game

Have a backup? Choose the game's APK and all its .obb files together, or one XAPK/APKS/APKM bundle containing a standalone APK. Split sets and Android/data restore are not supported here. Frame Control installs the app and puts its data in the right place.

In the desktop app, drop the backup folder or its APK. Matching game data in the same folder is found automatically.

Import from my Quest

Plug your Quest into this computer by USB, put it on, then Look for my Quest.
Copies games you own from your own Quest (developer mode on) to the Frame. A game with OBB data takes two imports: the first installs it; start it from the Steam library, then import again to copy its data in. Frame Control never starts the game itself. Games that use Meta's licence check install with a warning: on the Frame that check can't reach Meta, so they may quit, hang, or run without online features. Frame Control won't remove that check. Power & heat report

Observe battery, CPU, temperatures and available sensors without changing settings. One observation at a time, every five seconds, for at most five minutes.

No observation yet.

Download before starting again or quitting: only the latest observation is kept in memory. Downloads during collection are incomplete snapshots. Stop, disconnect or switching headsets keeps received samples, labeled with the original headset. A smoke session blocks sensor reads.

Open the saved HTML in your browser; it works offline and includes JSON/CSV downloads. Unknown readings are never treated as zero. Rails overlap; do not add them. Sensor accuracy is unverified. Reports include sensor paths and OS builds: review before sharing.

Steam desktop sharing Linux PC only

Help for Steam's own steam -pipewire desktop-in-headset flow on Wayland. Frame Control's Linux “PC in the headset” feature remains disabled. This helper needs no headset connection.

Save your games and exit Steam using Steam → Exit before launching. This launch does not save a setting or restart an existing Steam session.

Reset opens KDE's Application Permissions so you can revoke a verified Steam screen-sharing session yourself. Frame Control does not reset permissions automatically. Other desktops get guidance only.

KDE System Settings → Applications → Application Permissions → Steam Linux Runtime 3.0 → Screen sharing → Manage 1 Session → Revoke. Verify the session belongs to Steam. Never use Revoke All. If the entry is missing or ambiguous, stop.

VR comfort and performance

Waiting for the Frame
Compositor FPS measures SteamVR output, not game FPS. Application FPS is unavailable when no app supplies timing. GPU time is render time, not GPU utilisation. Battery and temperature are in the battery menu at the top.
The HUD is ours and uses the Frame’s built-in tools. Place its panel with SteamVR’s Float in World or controller docking controls. It updates every two seconds until closed.

Playspace and seated comfort

Tracking-origin controls are not available yet: reversible changes still need an idle-headset test. Use SteamVR’s recenter and room setup for now. A seated origin only affects apps that use seated tracking; it cannot force a game into seated mode.

For motion comfort, choose snap-turn, teleport movement and a movement vignette in each game’s settings. SteamVR has no verified universal snap-turn or locomotion-vignette switch.

Desktop low-battery alert

No session timer needed. Off when this page opens or you switch headsets. Uses normal status refreshes while the page is visible; no extra polling or headset changes. Two readings must confirm low charge and battery drain. One alert until charge recovers to 20%, with at least ten minutes between alerts.

Checking session…

A one-minute warning, then Steam Home. Games stay running: save and pause first. Keep this app open and connected for notifications.

How sessions and alerts work

This is a reminder, not a parental lock. The timer continues on the Frame if you disconnect; a headset restart cancels it. Cancel before changing settings. Set break/check-in to 0 to turn them off.

Battery, heat and check-in alerts appear on connected companions during a session. Headset warnings and break reminders continue without a companion. iOS may suspend phone notifications in the background. Breaks and check-ins count SteamVR activity, not confirmed wear time.

Move a game with Steam

On the headset, open Steam → Settings → Storage, choose the source drive, select the game, then choose Move and a destination. If Storage is unavailable in the headset UI, use desktop Steam’s Settings → Storage.

Steam offers destinations it supports. Let Steam finish and handle any errors, then Refresh here. Frame Control cannot verify a supported move API or its recovery behaviour, so it never moves or deletes game files.

Back up the Frame

Copies game saves, settings and Android app data from the headset to a dated folder on this computer. It only reads the headset. Games themselves aren't copied: reinstall them from Steam.

Never copied: Steam sign-in files (steam.token, config.vdf, loginusers.vdf), SSH keys, keyrings and other passwords. Backups aren't encrypted, and game folders can hold launcher logins, so keep them private. Close Android apps first: open ones are skipped.

Restore

Open this tool to see your backups.
After a factory reset, sign in to Steam, reinstall your games and start each once, and reinstall your Android apps. Then restore. Parts that can't go back yet are skipped, not failed. Files a restore replaces are kept on the headset in ~/.local/share/frame-control/restore-previous.

Play in VR with UEVR

UEVR by praydog turns many Unreal Engine games into VR games. Frame Control downloads the official UEVR 1.05 release and python.org's Windows Python, which it uses to load UEVR into the game (about 20 MB), checks their hashes, and keeps them in this game's Proton prefix, not the game's folder. Remove takes them out again.

Tested on the Frame with one game so far. Whether a game looks and plays right in VR varies; UEVR's own menu in the headset has the per-game settings.
